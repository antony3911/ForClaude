# 03. 申請材料與策略

> MS 申請的權重大致是：**學校背景與 GPA ≈ 相關經驗（研究、專題、實習） > SOP > 推薦信 > 英文**。
> 你的優勢是「已經有碩士研究經驗」；你要處理的是「為什麼要再讀一個碩士」。

---

## 3.1 選校配比

### 建議：MS 10–12 所，加上 PhD 備案 2–3 所

| 類型 | 數量 | 定義 |
|---|---|---|
| MS 夢幻 | 3 | 頂尖學校，而且**已確認你有申請資格**（例如 Stanford EE、CMU ECE） |
| MS 實力相當 | 5–6 | 就業資源好、地點好、你的背景有競爭力 |
| MS 保底 | 2–3 | 錄取率較高，但**畢業生出路要確實不錯**（看就業報告，不是看排名） |
| PhD 備案 | 2–3 | 教授研究高度對口；尤其是**不收第二碩士、但可以申請 PhD** 的學校（例如 Berkeley EECS 明確要求已有碩士者改申請 PhD） |

**鐵則**
- **先確認資格再放進名單**（見 [05](05-schools-and-labs.md#51-第一步確認第二碩士資格)），不然就是白繳申請費
- **看就業報告，不要只看排名**：很多學校公開 MS 畢業生的就業率、雇主清單和薪資中位數
- **同一所學校通常只能申請一個學位**，MS 和 PhD 要擇一，先查規定

## 3.2 Statement of Purpose（MS 版）

### 結構（約 1–2 頁或 ~1,000 字，依各校限制調整）

1. **開頭（1 段）**：你的職涯目標，以及驅動它的技術問題
   > 例：「I want to design the next generation of AI accelerators. My master's research on accelerating long-sequence protein structure prediction taught me that the hardest problems are not arithmetic, but data movement…」
2. **你已經做過什麼（2 段）**：碩士研究，重點放在**你做的工程決策與量化成果**
   - 問題 → 你的設計 → 困難與解決方式 → 量化結果（加速比、能效、記憶體節省）
   - ASIC implementation 的成果（PPA 數字）
3. **為什麼要再讀一個碩士（1 段，一定要寫）**：你的能力缺口在哪？為什麼現在的學程補不了？（範例見 [01 的 1.6 節](01-positioning-and-strategy.md#16-為什麼要再讀一個碩士要有好答案)）
4. **為什麼選這個學程（1 段，每校客製化）**：
   - **具體課程**：進階 VLSI、下線課程、驗證、計算機結構
   - 有興趣的**教授或實驗室**（想做 thesis 或 RA 的話）
   - 業界連結：實習課程、產業合作專案、地理位置
5. **結尾（2–3 句）**：畢業後想做什麼（例如在 AI 晶片團隊做 RTL 或 micro-architecture）

### SOP 常見地雷

- ❌ 「I have been passionate about … since I was a child」
- ❌ 沒有回答「為什麼要再讀一個碩士」，或者理由是「為了在美國工作」
- ❌ 貶低自己的台灣碩士學歷
- ❌ 所有學校用同一篇，只改校名
- ❌ 找代辦或 AI 生成整篇（見 [07](07-reality-check.md#76-學術誠信)）
- ✅ 具體、量化、有清楚的能力缺口與學習計畫

### PhD 備案的 SOP
PhD 的 SOP 要以**研究**為主軸：你想解決什麼研究問題、為什麼想跟這位教授。不能直接沿用 MS 版。骨架見 [10](10-templates.md#3-sop-骨架)。

## 3.3 CV

**你需要兩個版本：**

### (1) 申請用的學術 CV（1–2 頁）
1. Education
2. **Research Experience**（每項 2–4 個 bullet，強動詞開頭，加上量化結果）
   > 「Designed a tiled dataflow for triangle multiplicative updates on an HBM FPGA (Alveo U280), reducing off-chip traffic by 5.2× and achieving 3.1× speedup over an optimized A100 baseline at L = 2,048.」（數字為範例）
3. **Projects**：ASIC implementation（寫出製程、頻率、面積、功耗）
4. Publications（如果有；審稿中的也可以寫，誠實標示）
5. **Work Experience**（服役、研替或業界經驗）
6. Skills：
   - HDL/HLS：SystemVerilog, Verilog, Vitis HLS
   - EDA：Design Compiler/Genus, PrimeTime, ICC2/Innovus, VCS/Xcelium, Vivado
   - Verification：SVA, cocotb, UVM (basic)
   - Programming：Python (PyTorch), C++, Tcl

### (2) 求職用的業界履歷（**嚴格 1 頁**，入學前就要準備好）
- 美國格式：**不放照片、年齡、性別、婚姻狀況**
- 最上面放技能摘要與相關經驗
- 每個 bullet 都是「動作 + 技術 + 量化成果」
- 關鍵字對齊職缺描述（很多公司會用系統篩選履歷）

## 3.4 推薦信

### 組合（通常要 3 封）

| 優先順序 | 推薦人 | 為什麼 |
|---|---|---|
| 必備 | **碩士指導教授** | 最了解你的研究與工程能力 |
| 強烈建議 | **業界主管**（研替、工作、實習） | MS 是職業導向的學位，業界觀點很有說服力 |
| 建議 | 另一位知道你研究或修課表現的老師 | 補充第二個角度 |

### 怎麼讓推薦信寫得好
- 提供**資料包**（範本在 [10](10-templates.md#2-給推薦人的資料包brag-sheet)）：CV、SOP 草稿、具體事例、各校截止日
- **至少提前 6–8 週請託**，截止日前 2 週禮貌提醒
- 情境 B 的話：畢業後和老師保持聯繫，不要等到要寫信時才突然出現

### ⚠️ 不要自己寫推薦信給老師簽
台灣很常見，但**強烈不建議**：三封信的口吻會很像，內容空泛，也有誠信問題。如果老師要求提供草稿，給**事實清單與具體事例**，不要給一封寫好的信。

## 3.5 MS 學生聯繫教授（RA 與 thesis）

MS 申請**通常不需要**事先聯繫教授（錄取由系上決定）。但你的研究背景讓你有機會爭取：
- **RA（研究助理）**：有些學校的 RA 含學費減免或薪水，可以大幅降低花費
- **Thesis option**：做研究型碩士，拿到美國教授的推薦信（將來轉 PhD 很有用）
- **Grader／TA**：部分學校開放給 MS 學生

### 什麼時候聯繫
- **錄取後到入學前（3–7 月）**：最有效，因為你已經是「確定會來的學生」
- 入學後第一週：直接去教授的 office hour

### 怎麼寫
- 短、具體，附上 CV 和研究摘要
- 說明你能**立刻貢獻**的能力（例如「我有 FPGA 加速器與 ASIC flow 經驗，可以協助 X 專案」）
- 範本可以參考 [10](10-templates.md#5-錄取後聯繫教授的信rathesis) 修改

> 期待值：MS 學生拿到 RA 的機會不高，尤其是有學費減免的 RA。**不要把它當成預算的一部分**，拿到算是紅利。

## 3.6 其他加分項

- **GitHub**：ASIC implementation、FPGA 加速器，以及可參數化的 systolic array 與完整 testbench
- **LinkedIn**：美國求職必備，入學前就建好
- **個人網站**：一頁式就好（研究摘要、專案、CV）
- **業界經驗**：研替或 IC 設計公司的工作經驗，對 MS 申請和之後的求職都是明顯加分

## 3.8 費用估算

### 申請階段（約）

| 項目 | 金額（約） |
|---|---|
| 申請費 | 每校 US$75–150 × 12–15 所 ≈ US$900–2,200 |
| TOEFL | 每次約 US$200 以上 × 1–2 次 |
| 送分 | 每校約 US$20–30 |
| GRE（多半不需要） | 約 US$220 以上 |
| **合計** | **約 NT$6–10 萬** |

### 就學階段（MS 自費）

| 項目 | 金額（約） |
|---|---|
| 學費 | 公立學校（州外學生）約 US$3.5–6 萬／年；私立學校約 US$5.5–7.5 萬／年 |
| 生活費 | 約 US$2–4 萬以上／年（Bay Area、NYC、Boston 最貴，中西部最便宜） |
| 健康保險 | 約 US$3,000–6,000／年（學校保險，通常是強制的） |
| **總計（1.5–2 年）** | **約 US$9–20 萬（約 NT$300–650 萬）** |

> 以上是粗估，**以各校官方的 Cost of Attendance 為準**。同樣是頂尖學校，公立和私立的總花費可能差到 US$5 萬以上。

### 減輕負擔的方法

| 來源 | 說明 |
|---|---|
| **教育部留學獎學金** | **碩士也適用**；須已有入學許可或已在學；一般生每年約 US$16,000，最長 2 年（以當年簡章為準） |
| 教育部公費留學考試 | 考試制；請詳讀簡章中的權利義務（例如是否有返國服務要求） |
| 學術交流基金會（Fulbright Taiwan） | 免費的 EducationUSA 諮詢，以及赴美進修的獎助項目（每年調整） |
| **學校的 RA／TA／grader** | 部分職位含學費減免或薪水；MS 能拿到的名額有限 |
| 學系獎學金 | 有些 MS 錄取會附帶部分獎學金；可以禮貌地詢問 |
| 留學貸款 | 教育部有留學貸款方案（條件與利率見當年公告）；要評估還款壓力與匯率風險 |
| 民間基金會、企業獎學金 | 每年種類不同，查教育部公費留學資訊網和學校國際處 |

> 注意：教育部「世界百大合作設置獎學金」**只限 PhD**，只和你的 PhD 備案有關。

## 3.9 Offer 評估

MS 的 offer 評估，重點和 PhD 完全不同：

| 面向 | 要看的 |
|---|---|
| **就業成果** | 學程的就業報告：就業率、主要雇主、薪資中位數。**有沒有 AI 晶片公司？** |
| **總花費** | 學費 + 生活費 + 保險；有沒有獎學金或 RA 機會 |
| **實習政策（CPT）** | **2026/08 SEVP 收緊 CPT 之後，這一點變得非常關鍵**：實習是不是必修？學校目前怎麼處理 CPT？（見 [07](07-reality-check.md#71-政策變動總表)） |
| **課程** | 有沒有下線課程、進階 VLSI、驗證、計算機結構？**會不會跟你在台灣修過的課重複？** |
| **學程長度** | 3 學期還是 4 學期？（影響花費和 H-1B 抽籤次數，見 [02](02-timeline.md#24-入學後從第一學期到-h-1b以情境-a-為例)） |
| **班級規模** | 國際 MS 學生很多的學程，選課和求職的競爭也更激烈 |
| **Career services** | Career fair 的規模、有哪些公司參加、校友內推文化 |
| **地點** | 離晶片公司近不近（見 [06](06-geography.md)） |
| **STEM 認定** | I-20 上的 CIP 代碼是否屬於 STEM（EE/CE 通常是，但要確認） |
| **Thesis／RA 機會** | 想保留 PhD 選項的話很重要 |
| **台灣校友** | 目標公司裡有沒有這個學程的台灣學長姐？（內推和資訊） |

**找在學學生或剛畢業的學長姐聊**：「你們那屆的國際學生，大概多少比例在畢業 3 個月內找到工作？」
