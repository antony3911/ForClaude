# 已經幫你下載好的工具

從 GitHub 下載、原封不動放在這裡（都是 GPL 授權，授權檔在 zip 裡），之後做正式模型時用。

| 檔案 | 是什麼 | 怎麼裝 |
|---|---|---|
| `RE-Mesh-Editor.zip`（0.66 版，2026-04） | Blender 外掛：讀寫 RE 引擎模型、轉換貼圖 | Blender（4.3.2～5.0）→ 編輯 → 偏好設定 → 外掛 → 從磁碟安裝 → 選這個 zip |
| `RE-Asset-Library.zip`（0.25 版，2026-04） | Blender 外掛：在 Blender 裡瀏覽、解出遊戲檔案，也是做 patch pak 的必要工具 | 同上 |

## 沒辦法幫你下載的（要你自己載）

| 東西 | 原因 | 去哪載 |
|---|---|---|
| REFramework（荒野版） | GitHub 上「穩定版」是 2025 年 3 月的，大概跟不上現在的遊戲版本；新版在 nightly 頁面，我這邊看不到檔案清單，沒辦法確認哪個檔才對 | https://github.com/praydog/REFramework-nightly/releases → 最新一版裡的 `MHWILDS.zip` |
| Fluffy Mod Manager | 官網（fluffyquack.com）和 Nexus 在這個環境連不上 | Nexus Mods |
| Armor VFX Manager、VFX Unleashed | 在 Nexus，連不上；而且 Nexus 要登入帳號才能下載 | Nexus Mods（4908、4842） |
| MDF-XL | GitHub 上抓得到腳本，但它還需要另一個前置（_ScriptCore），那個我找不到 | Nexus Mods（125）一起裝比較保險 |
| Blender | 檔案很大，而且要裝在你的電腦上 | https://www.blender.org/download/ |

**不管哪一個，都要你在自己電腦上放進遊戲資料夾或 Blender**：我在雲端，碰不到你的電腦。
