# 02. 時程規劃

> MS 的時程分兩段：**申請前**（以 T = 送件截止月為基準往回推），以及**入學後**（從第一學期的求職，到畢業後的 OPT 與 H-1B）。
> MS 的截止日多落在 **12 月中到 2 月**（例如 Georgia Tech MS ECE 的 Fall 2027 截止日是 12/16）。你的送件時間是 **2028/12 – 2029/01**。有些學校分成好幾輪審核，**越早送件越有利**（名額與獎學金都是）。

---

## 2.1 你的時程（役男版）

**前提**：你現在碩一（2026/09），預計 2028 年夏天畢業，民國 83–93 年次（兵役為 4 個月軍事訓練役）。如果不符合，請把日期平移。
**結論**：因為你是役男、而且打算在美國就業，**出國前一定要先把兵役當完**（原因見 [07](07-reality-check.md#74-役男兵役)）。所以你的入學時間是 **2029 Fall**。

### 三條兵役路線

| | **路線 1：分階段軍事訓練**（建議先申請） | 路線 2：畢業後一次服完 4 個月 | 路線 3：研發替代役 |
|---|---|---|---|
| 怎麼做 | 用**連續兩個暑假**（2027、2028）把 4 個月當完 | 畢業後入營（可以申請「優先入營」，自己選時間） | 碩士畢業後在科技公司服役 |
| 申請 | **2026/10/15 – 11/15** 在內政部役政司網站線上申請；每年約 1,100 個名額，**超額時抽籤** | 畢業前後向戶籍地公所辦理 | 碩士期間報名、參加用人單位甄選 |
| 服完時間 | 約 2028 年 8 月底 | 依入營梯次，約 2028 年底 | 役期 3 年，約 2031 年 |
| 優點 | **最省時間**：畢業時兵役幾乎已經完成 | 不用搶名額 | 有薪水，累積 3 年業界經驗 |
| 缺點 | 兩個暑假不能做研究或實習；可能抽不到 | 服役期間正好是申請季，**文件要在入營前準備好** | 出國時間最晚 |
| 入學 | 2029 Fall | 2029 Fall | 約 2032 |

**分階段軍事訓練的細節**（以 2025–2026 梯次為例）：
- 第一階段在第一年暑假（例如 6/8–9/2），第二階段在第二年暑假（例如 7/5–8/27）
- 每年有 3 個入營梯次可以選；2026 年的梯次規劃預計在 9 月底前公告
- 如果第二階段沒完成、又沒有緩徵事由，會依徵集令入營把剩下的役期補完
- **如果你在第二階段之前就畢業了，能不能照常接第二階段，請直接向役政司確認**

**建議**：**先申請路線 1**（沒抽到也沒有損失），沒抽到再走路線 2。路線 3 只有在你想先累積多年業界經驗時才考慮。

### 推薦時程（路線 1 或 2 → 2029 Fall 入學）

| 時間 | 事項 |
|---|---|
| **2026/10/15 – 11/15** | **申請分階段軍事訓練**（路線 1） |
| 2026/09 – 2027/06 | 研究、ASIC synthesis、TOEFL 準備、RTL 面試基本功 |
| 2027 暑假 | 第一階段軍事訓練（路線 1） |
| 2027/09 – 2028/06 | 研究收尾與投稿、ASIC APR、**第一次 TOEFL**、**寫信確認第二碩士資格**、選校名單成形 |
| 2028/06 前 | **離開學校前，先跟推薦人約好**，並提供資料包 |
| 2028 暑假 | 畢業；第二階段軍事訓練（路線 1）或入營（路線 2） |
| 2028/09 – 11 | SOP 定稿、送分、請推薦人上傳 |
| **2028/12 – 2029/01** | **送件** |
| 2028/09 – 2029/07 | **建議在台灣的 IC 設計公司工作或當研究助理**（業界經驗對申請與美國求職都加分，也能存學費） |
| 2029/02 – 04 | 錄取、比較 offer |
| **2029/08** | **入學** |
| 2030/12 或 2031/05 | 畢業 → OPT → H-1B 抽籤 |

> **關於 2029 Spring 入學**：如果兵役在 2028 年 8 月前服完，也可以申請 2029 年 1 月入學。Spring 的截止日多在前一年的 8–10 月，但不是每個學程都有 Spring 入學，而且第一學期結束就要找實習，時程很趕。**除非你很想早點出國，否則 2029 Fall 比較穩。**

> **關於畢業後的工作**：如果應徵時公司知道你只會待一年，可能會影響錄用。你可以誠實討論（有些公司接受），或者改找約聘、研究助理類的職位。

## 2.2 申請前 checklist

### 階段 0：定方向（現在，2026/09）

- [ ] **2026/10/15 – 11/15 申請分階段軍事訓練**（見 2.1）
- [ ] **預算**：自費 US$9–20 萬，家裡能支援多少？要不要貸款？（見 [03](03-application-materials.md#38-費用估算)）
- [ ] 和指導教授確認留學計畫、研究投稿目標，以及推薦信
- [ ] TOEFL 模擬考，確認起點
- [ ] 列出 20 個 MS 候選課程，開始**逐一確認第二碩士資格**（見 [05](05-schools-and-labs.md#51-第一步確認第二碩士資格)）

### 階段 1：能力建構（T−15 ~ T−7）

**研究與 ASIC**
- [ ] 完成加速器主要設計與實驗
- [ ] ASIC synthesis → APR → PPA（見 [01 的 1.7 節](01-positioning-and-strategy.md#17-從-fpga-銜接到-asic出國前最值得投資的事)）
- [ ] 如果時間允許，投稿論文（見 2.3）

**英文**
- [ ] 每天 30–45 分鐘：技術演講聽力 + shadowing（[04](04-english.md)）

**面試能力（MS 特有，現在就開始）**
- [ ] 每週 2–3 題 RTL 手寫：FIFO、arbiter、FSM、CDC（[08](08-skills-roadmap.md#86-業界面試準備ms-的核心)）

### 階段 2：考試與名單（T−7 ~ T−4）

- [ ] **第一次 TOEFL 正式考試**（最晚在 T−5；成績有效期 2 年）
- [ ] 還沒確認資格的學校，**寄信向系所確認**（範本在 [10](10-templates.md#1-詢問系所第二碩士資格的信)），**保留書面回覆**
- [ ] 確認有沒有學校要求 GRE（多數不需要）
- [ ] 名單收斂到 10–12 所 MS，加上 2–3 所 PhD 備案
- [ ] 跟推薦人非正式地打招呼

### 階段 3：文件撰寫（T−4 ~ T−1）

- [ ] SOP v1 → v3，**包含「為什麼要再讀一個碩士」**（見 [01 的 1.6 節](01-positioning-and-strategy.md#16-為什麼要再讀一個碩士要有好答案)）
- [ ] CV 定稿（業界格式也準備一份，見 [03](03-application-materials.md#33-cv)）
- [ ] 必要時第二次 TOEFL
- [ ] 準備推薦人資料包，**至少在截止日前 6–8 週正式請託**
- [ ] 申請系統開放（約 9 月）後建立帳號，整理各校要求
- [ ] 如果有 PhD 備案：9–11 月寄信聯繫教授

### 階段 4：送件與錄取（T ~ T+4）

- [ ] 目標在截止日前 2 週送出；分輪次審核的學校，搶第一輪
- [ ] 截止日前 2 週，禮貌提醒推薦人
- [ ] 2–4 月：錄取結果陸續公布（MS 通常不面試）
- [ ] **錄取後寄信給有興趣的教授**，詢問 RA 或 thesis 機會（對 MS 來說，錄取後才聯繫比較有效，見 [03](03-application-materials.md#35-ms-學生聯繫教授ra-與-thesis)）
- [ ] 比較 offer（見 [03 的 3.9 節](03-application-materials.md#39-offer-評估)），在期限內繳交訂金（deposit）
- [ ] 準備財力證明，申請 I-20
- [ ] 查教育部留學獎學金的報名時間（通常在年初，需要已有入學許可或已在學）

### 階段 5：出國準備（T+4 ~ T+8）

- [ ] 繳 SEVIS I-901 費用、填 DS-160、預約 AIT 面談（社群媒體要設為公開）
- [ ] 役男：申請出境核准（如果適用）
- [ ] **面試能力衝刺**：RTL、STA、驗證、計結，都要能用英文講（見 [08](08-skills-roadmap.md#86-業界面試準備ms-的核心)）
- [ ] **準備美國格式的一頁履歷**，建好 LinkedIn，列出目標公司清單
- [ ] 疫苗與健康檢查、找房、銀行、手機
- [ ] 入境（F-1 最早可以在開學日前 30 天入境）

## 2.3 研討會投稿時程（參考）

MS 申請不一定需要論文，但有論文是明顯加分，也保留 PhD 的可能。以下是大約的月份，逐年會變，以官網為準。

| 研討會 | 投稿截止（約） | 適合度 |
|---|---|---|
| **FPGA**（ISFPGA） | 9–10 月 | ★★★ 你的 FPGA 設計 |
| **FCCM** | 12–1 月 | ★★★ |
| **FPL** | 3–4 月 | ★★ |
| **DAC** | 11 月 | ★★★ co-design 主場 |
| **ICCAD** | 4 月 | ★★★ |
| **DATE** | 9 月 | ★★ |
| **ASP-DAC** | 7 月 | ★★ |
| **ISLPED** | 2–3 月 | ★★ |
| **ICCD** | 6 月 | ★★ |
| **MICRO／HPCA／ISCA** | 4 月／7–8 月／11 月 | ★★★ 難度最高 |

> 審稿中（under review）的論文可以寫在 CV 上，只要誠實標示就好。很多會議是 double-blind，放 arXiv 前先讀匿名規定。

## 2.4 入學後：從第一學期到 H-1B（以 2029 Fall 入學為例）

**這張表是 MS 路線的核心。**

| 時間 | 事件 | 你該做的 |
|---|---|---|
| 2029/08 | 入學 | 參加新生說明會，**向國際學生辦公室確認 CPT 規定** |
| **2029/08 – 11** | **暑期實習招募高峰**（career fair 多在 9 月） | 大量投遞、參加 career fair、請校友內推；**這時就要能面試** |
| 2029/12 – 2030/03 | 較晚招募的公司、新創 | 還沒拿到實習就繼續找；也可以爭取 RA 或校內專案 |
| **2030/05 – 08** | **暑期實習**（CPT） | 全力表現，爭取 **return offer**（正職邀約） |
| 2030/08 – 11 | **正職招募** | 有 return offer 的話，評估是否接受；沒有就全力找 |
| 畢業前 90 天內 | 申請 OPT | OPT 可以在畢業前 90 天到畢業後 60 天之間申請 |
| **2030/12**（3 學期） | 畢業 → OPT 開始 | OPT 期間累計失業不能超過 90 天 |
| **2031/03** | **第 1 次 H-1B 抽籤**（雇主登記） | 中籤 → 同年 10/1 起轉為 H-1B |
| OPT 到期前 90 天內 | 申請 STEM OPT（+24 個月） | 雇主必須加入 E-Verify；總失業天數上限變成 150 天 |
| 2032/03、2033/03 | 第 2、3 次 H-1B 抽籤 | 同時準備 Plan B（見 [07](07-reality-check.md#72-工作簽證與移民路徑的現實)） |

### 3 學期 vs 4 學期

| | 3 學期（12 月畢業） | 4 學期（隔年 5 月畢業） |
|---|---|---|
| 花費 | 較少 | 多一學期的學費和生活費 |
| 實習 | 中間一個暑假 | 中間一個暑假 |
| 修課 | 較緊湊 | 可以多修進階課（例如下線課程） |
| H-1B 抽籤次數 | 通常 3 次 | 如果在畢業前的 3 月就拿到正職 offer，雇主可以在畢業前先幫你登記，**理論上可能多一次**（要看 OPT 起訖日與雇主安排，請跟學校的國際學生辦公室確認） |

### 關鍵提醒

- **Cap-gap**：H-1B 申請審理期間，如果 OPT 到期，F-1 身分和工作許可可以延長。2025 年的新規則把延長期限放寬到**隔年 4/1**
- **失業天數**：OPT 期間 90 天、加上 STEM OPT 共 150 天；超過就違反身分規定，而且沒有寬限期
- **1 年制課程（例如 Cornell MEng）**：沒有暑期實習的空檔，入學第一學期就要找正職
