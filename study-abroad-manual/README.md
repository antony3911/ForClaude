## 1. 一頁結論（TL;DR）

1. **⚠️ 碩二這一年是關鍵，畢業後就用不到學校資源了。** ASIC 實作（synthesis、APR、PPA）、論文投稿、GitHub 作品、第一次 TOEFL，還有跟推薦人約好，**都要在 2027/06 前完成**。詳見 [02 的 2.2 節](02-timeline.md#22-你的逐期-checklist)。
2. **一定要先當兵再出國。** 沒當兵的役男畢業後就不再是在學身分，役政單位會催告你 3 個月內返國，所以不能在美國用 OPT 工作。**你的做法：2027 年 5–6 月申請「優先入營」，畢業後一次服完 4 個月**。分階段軍事訓練要跨 2027、2028 兩個暑假，不適合 2027 年就畢業的你。詳見 [07](07-reality-check.md#74-役男兵役)。
3. **「第二個碩士」在很多學校會卡關，選校第一步就是確認資格。**
   - ✅ 明確可以：USC、Northeastern
   - 🟡 看起來可以：ASU、UF、Utah、Portland State、Georgia Tech、CMU、Stanford
   - 🔴 原則上不收：UC Berkeley、UCSD、UIUC、Michigan、NC State、University of Arizona
   - ❓ 要寫信問：Texas A&M、UT Dallas、San José State、Santa Clara 等
   - 詳見 [05](05-schools-and-labs.md#51-第一步確認第二碩士資格)
4. **你的主力學校**：USC、Arizona State、Texas A&M、UT Dallas、Northeastern、San José State、Santa Clara，再加上 Portland State、UF、Utah 當穩健選項。這些學校的共同點是**晶片業界認識、就在產業聚落旁邊或校友多**。預算夠的話，可以丟 1–2 間 Georgia Tech 或 CMU 試試。詳見 [05 的 5.2 節](05-schools-and-labs.md#52-你的選校名單中山電機所成績中上)。
5. **學校背景和 GPA 已經定了，要靠三件事拉開差距**：ASIC 實作（PPA 數字）、研究成果（有投稿就寫），以及**退伍後約 1.5 年的台灣業界經驗**。業界經驗同時能帶來業界推薦信和學費存款。
6. **MS 是一張「進入美國晶片業招募管道的門票」。** 代價約 US$9–20 萬，換到美國學歷、實習機會、最多 3 年的 OPT，以及 3 次 H-1B 抽籤機會。
7. **H-1B 是最大的風險。** 新鮮人職位如果被歸在最低的 Level I，中籤率估計只有約 15%。一定要有 Plan B，例如先調到公司的台灣據點，再用 L-1 轉調回美國。詳見 [07](07-reality-check.md#72-工作簽證與移民路徑的現實)。
8. **求職從入學第一天就開始**：實習招募在 8–11 月，**RTL 面試能力要在出國前練好**。
9. **CPT 在 2026/08 變嚴了**：選校時要問清楚實習怎麼處理，實習列為必修的課程比較安全。
10. **英文**：TOEFL 目標 overall 5.0–5.5（約等於舊制 100 分以上）。多數 MS 不需要 GRE。

## 4. 這份手冊的使用方式

- **時效性標記**：寫著「（2026/09 狀態）」的內容，是依撰寫當下的公開資訊整理，**一定會變**。做決定前請到 [09](09-resources.md) 列的官方來源再確認一次。
- **第二碩士資格**：資格表是依各校公開資訊整理的，**最後以系所的書面回覆為準**。
- **選校分組**：這是依學校整體競爭度做的粗略判斷，不是錄取機率，請搭配學長姐的實際錄取紀錄參考。
- 這份手冊放在 git 裡，你可以直接修改，把它變成自己的申請日誌。
