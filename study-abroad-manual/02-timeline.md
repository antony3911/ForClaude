# 02. 時程規劃

> **你的狀況**：民國 92 年次，現在（2026/09）碩二剛開始，預計 **2027 年夏天畢業**。兵役是 4 個月的軍事訓練役。
> **結論**：碩二這一年把能在學校做的事做完 → 2027 年畢業後馬上當兵 → 退伍後在台灣工作 → **2028/12 送件、2029 Fall 入學**（也就是你說的「一年半後開始申請」）。

---

## 2.1 你的時程（役男版）

### 兵役：畢業後申請「優先入營」，一次服完 4 個月

| 選項 | 適合你嗎 | 說明 |
|---|---|---|
| **畢業後優先入營** | ★★★ **推薦** | 每年約 5–6 月線上申請（2026 年是 5/11–6/11），畢業後就能盡早入營。依內政部規劃，2027 年陸軍的入營時間在 7–10 月，海軍、陸戰隊、空軍在 7–9 月 |
| 分階段軍事訓練 | ✗ 不適合 | 要跨 2027、2028 兩個暑假，但你 2027 年就畢業了，第二階段會卡在畢業後，而且會打斷工作 |
| 研發替代役 | ✗ 不適合 | 役期 3 年，出國會延到 2030 年以後 |

> 為什麼一定要先當兵：沒當兵的役男畢業後就不再是在學身分，役政單位會催告你 3 個月內返國，所以不能在美國用 OPT 工作。詳見 [07](07-reality-check.md#74-役男兵役)。

### 兩條入學路線

| | **路線乙：2029 Fall 入學（推薦）** | 路線甲：2028 Fall 入學（最快） |
|---|---|---|
| 送件 | 2028/12 – 2029/01 | 2027/12 – 2028/01（剛退伍） |
| 入學前的業界經驗 | **約 1.5 年**（在台灣 IC 設計公司） | 無 |
| 準備時間 | 充裕：碩二打底，工作期間準備文件 | **很趕**：TOEFL、SOP、推薦信都要在**入營前（2027/07）**完成 |
| 資金 | 工作 1.5 年能存下一部分學費 | 全靠家裡或貸款 |
| 對申請的幫助 | 業界經驗、業界推薦信、更成熟的作品 | 研究成果比較新鮮 |
| 對美國求職的幫助 | 有業界經驗，面試更有話題，也可能拿到較高的職級 | 新鮮人 |

**建議走路線乙**。對中段學校的 MS 申請和之後的美國求職來說，1.5 年的台灣業界經驗是很實在的加分，也能減輕財務壓力。
只有在「碩二結束前 TOEFL、SOP、推薦信都能搞定，而且資金沒問題」的情況下，才考慮路線甲。

### 另一個要留意的選項：美商台灣分公司
如果退伍後進入 **NVIDIA、AMD、Intel、Google、Apple、Qualcomm、Marvell、Synopsys、Cadence 等的台灣團隊**：
- 做滿 1 年後，**理論上有機會用 L-1 轉調美國**（不用抽 H-1B、不用付學費），但要看公司政策和部門需求，你無法掌控
- 到了 2028 年中要決定是否送件時，可以比較「繼續在公司爭取轉調」和「出國讀 MS」哪條路比較好

## 2.2 你的逐期 checklist

### 碩二上（2026/09 – 2027/01）：研究與 ASIC 衝刺

**⚠️ 畢業後就不能再用學校的 EDA 工具和 TSRI 資源了，ASIC 相關的事一定要在碩二做完。**

- [ ] 跟指導教授談你的規劃（2027 畢業 → 當兵 → 工作 → 2029 出國），以及論文投稿目標
- [ ] **ASIC synthesis**：用 Design Compiler 或 Genus 合成核心運算單元，拿到面積、功耗、頻率（見 [01 的 1.7 節](01-positioning-and-strategy.md#17-從-fpga-銜接到-asic出國前最值得投資的事)）
- [ ] 研究主要結果，**瞄準 FCCM（約 1 月截止）或 ISLPED（約 2–3 月）**
- [ ] TOEFL 開始準備（每天 30–45 分鐘）
- [ ] RTL 面試基本題：每週 2–3 題（[08](08-skills-roadmap.md#86-業界面試準備ms-的核心)）

### 碩二下（2027/02 – 2027/06）：收尾、考試、找工作

- [ ] **ASIC APR** 完成，產出 post-layout 的 PPA 和 layout 截圖
- [ ] 論文投稿：**ICCAD、FPL、MICRO（約 3–4 月截止）**，或者把碩論改寫成投稿版本
- [ ] **第一次 TOEFL 正式考試**（成績有效 2 年，2027 年春天考的成績可以用到 2028/12 的申請季）
- [ ] 把 FPGA 加速器、ASIC 流程、testbench 整理到 **GitHub**（離開學校前）
- [ ] **找退伍後的工作**：台灣 IC 設計公司通常在春天招募應屆畢業生。應徵時說明你 2027 年秋天退伍，可以之後到職
- [ ] **5–6 月：線上申請優先入營**
- [ ] **跟推薦人約好**：說明你會在 2028/12 申請，請老師屆時幫忙；**現在就交給老師資料包**（範本在 [10](10-templates.md#2-給推薦人的資料包brag-sheet)）。記憶還新的時候，可以請老師先寫一份草稿存起來
- [ ] 畢業、口試

### 服役（約 2027/07 – 2027/11）

- [ ] 專心當兵。可以利用零碎時間複習 RTL 面試題、背 TOEFL 單字
- [ ] 退伍後的工作報到時間確認

### 工作第一年上半（2027/12 – 2028/05）：累積經驗、開始申請準備

- [ ] 在工作中爭取 RTL、驗證、physical design 相關的任務（**這會直接變成履歷和 SOP 的內容**）
- [ ] **2028/03 起：正式開始申請流程**
  - [ ] 選校名單（[05 的 5.2 節](05-schools-and-labs.md#52-你的選校名單中山電機所成績中上)）放進追蹤表
  - [ ] **寫信給各系所，確認第二碩士資格**（範本在 [10](10-templates.md#1-詢問系所第二碩士資格的信)），保留書面回覆
  - [ ] 確認各校的 TOEFL 門檻和 GRE 要求
- [ ] 如果 TOEFL 分數不夠：這段期間再考一次

### 申請季（2028/06 – 2029/01）

- [ ] 6–8 月：SOP v1 → v3（「為什麼要再讀一個碩士」加上業界經驗，見 [03](03-application-materials.md#32-statement-of-purposems-版)）、CV 更新
- [ ] 8–9 月：**正式請託推薦人**（至少在截止日前 6–8 週）。建議其中一封找**工作上的主管**
- [ ] 9 月：申請系統開放，建立帳號；送 TOEFL 成績
- [ ] 10–11 月：各校客製化段落
- [ ] **2028/12 – 2029/01：送件**（有分輪次審核的學校，搶第一輪）
- [ ] 截止日前 2 週，禮貌提醒推薦人

### 錄取到出國（2029/02 – 2029/08）

- [ ] 2–4 月：錄取結果陸續公布、比較 offer（[03 的 3.9 節](03-application-materials.md#39-offer-評估)）、繳訂金
- [ ] 查教育部留學獎學金的報名時間（需要已有入學許可）
- [ ] 準備財力證明 → 申請 I-20
- [ ] SEVIS I-901 費用、DS-160、AIT 簽證面談（**社群媒體要設為公開**）
- [ ] 向公司提離職（依公司規定提前告知）
- [ ] **面試能力衝刺**：RTL、STA、驗證、計結，都要能用英文講；美國格式的一頁履歷、LinkedIn
- [ ] 疫苗、健檢、牙齒；找房；入境（最早在開學日前 30 天）

## 2.3 研討會投稿時程（參考）

> **你實際能投的**：你在學校只剩碩二這一年，比較可行的是 **FCCM（約 1 月）、ISLPED（約 2–3 月）、ICCAD／FPL／MICRO（約 3–4 月）**。畢業後如果老師願意繼續指導修改，被拒的論文還可以轉投其他會議。

MS 申請不一定需要論文，但有論文是明顯加分，也保留 PhD 的可能。以下是大約的月份，逐年會變，以官網為準。

| 研討會 | 投稿截止（約） | 適合度 |
|---|---|---|
| **FPGA**（ISFPGA） | 9–10 月 | ★★★ 你的 FPGA 設計 |
| **FCCM** | 12–1 月 | ★★★ |
| **FPL** | 3–4 月 | ★★ |
| **DAC** | 11 月 | ★★★ co-design 主場 |
| **ICCAD** | 4 月 | ★★★ |
| **DATE** | 9 月 | ★★ |
| **ASP-DAC** | 7 月 | ★★ |
| **ISLPED** | 2–3 月 | ★★ |
| **ICCD** | 6 月 | ★★ |
| **MICRO／HPCA／ISCA** | 4 月／7–8 月／11 月 | ★★★ 難度最高 |

> 審稿中（under review）的論文可以寫在 CV 上，只要誠實標示就好。很多會議是 double-blind，放 arXiv 前先讀匿名規定。

## 2.4 入學後：從第一學期到 H-1B（以 2029 Fall 入學為例）

**這張表是 MS 路線的核心。**

| 時間 | 事件 | 你該做的 |
|---|---|---|
| 2029/08 | 入學 | 參加新生說明會，**向國際學生辦公室確認 CPT 規定** |
| **2029/08 – 11** | **暑期實習招募高峰**（career fair 多在 9 月） | 大量投遞、參加 career fair、請校友內推；**這時就要能面試** |
| 2029/12 – 2030/03 | 較晚招募的公司、新創 | 還沒拿到實習就繼續找；也可以爭取 RA 或校內專案 |
| **2030/05 – 08** | **暑期實習**（CPT） | 全力表現，爭取 **return offer**（正職邀約） |
| 2030/08 – 11 | **正職招募** | 有 return offer 的話，評估是否接受；沒有就全力找 |
| 畢業前 90 天內 | 申請 OPT | OPT 可以在畢業前 90 天到畢業後 60 天之間申請 |
| **2030/12**（3 學期） | 畢業 → OPT 開始 | OPT 期間累計失業不能超過 90 天 |
| **2031/03** | **第 1 次 H-1B 抽籤**（雇主登記） | 中籤 → 同年 10/1 起轉為 H-1B |
| OPT 到期前 90 天內 | 申請 STEM OPT（+24 個月） | 雇主必須加入 E-Verify；總失業天數上限變成 150 天 |
| 2032/03、2033/03 | 第 2、3 次 H-1B 抽籤 | 同時準備 Plan B（見 [07](07-reality-check.md#72-工作簽證與移民路徑的現實)） |

### 3 學期 vs 4 學期

| | 3 學期（12 月畢業） | 4 學期（隔年 5 月畢業） |
|---|---|---|
| 花費 | 較少 | 多一學期的學費和生活費 |
| 實習 | 中間一個暑假 | 中間一個暑假 |
| 修課 | 較緊湊 | 可以多修進階課（例如下線課程） |
| H-1B 抽籤次數 | 通常 3 次 | 如果在畢業前的 3 月就拿到正職 offer，雇主可以在畢業前先幫你登記，**理論上可能多一次**（要看 OPT 起訖日與雇主安排，請跟學校的國際學生辦公室確認） |

### 關鍵提醒

- **Cap-gap**：H-1B 申請審理期間，如果 OPT 到期，F-1 身分和工作許可可以延長。2025 年的新規則把延長期限放寬到**隔年 4/1**
- **失業天數**：OPT 期間 90 天、加上 STEM OPT 共 150 天；超過就違反身分規定，而且沒有寬限期
- **1 年制課程（例如 Cornell MEng）**：沒有暑期實習的空檔，入學第一學期就要找正職
