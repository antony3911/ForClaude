# 美國研究所留學手冊：Digital IC × AI 加速器方向

> 最後更新：2026-09-26
> 對象：台灣 EE/CS 研究生，目前在 HW/SW co-design 實驗室做 FPGA 加速器，研究題目是**長序列蛋白質結構預測的加速**；目標是赴美讀研究所，之後留在美國做 digital IC design，往 AI accelerator 發展。

## 1. 一頁結論（TL;DR）

1. **先決定 PhD 還是 MS，這個決定會影響後面所有事。** AI 加速器的 architecture／research 類職位主要走 PhD；RTL、DV、PD 這類職位讀 MS 就夠。你已經有研究題目和 co-design 背景，**建議以 PhD 為主**（通常全額資助），詳見 [01](01-positioning-and-strategy.md)。
2. **你最大的資產**是「domain-specific accelerator 加上真實 workload」的研究故事；**最大的缺口**是 ASIC 經驗。接下來 12 個月，請把 FPGA 設計的核心運算單元做一版 ASIC implementation（synthesis → APR → PPA 報告）。
3. **送件前至少要有一篇第一作者論文**（已接受或審稿中皆可，例如 DAC/ICCAD/FCCM/FPGA/FPL/MICRO/HPCA 或 workshop），再加上開源程式碼。
4. **研究包裝要能「泛化」**：不要只說「我加速了 AlphaFold」，要說「我解決了 pair representation 的 O(L²) 記憶體與 triangle 運算的 O(L³) 資料搬移問題」，而且方法能延伸到 long-context LLM。**ISCA 2025 已經有 LightNobel 做類似題目**，你必須讀透並做出差異化。
5. **選校以「教授」為單位，而不是看排名。** 先找 20–30 位潛在指導教授，最後收斂到 10–14 所學校。名單與找法見 [05](05-schools-and-labs.md)。
6. **英文**：TOEFL 從 2026 年 1 月起改成 1–6 級分制。目標 overall 5.0–5.5（約等於舊制 100 分以上），口說分數會影響 TA 資格，也就是會影響收入。**GRE**：多數頂尖 EE PhD 已不需要（MIT 不採用、Berkeley 不收），詳見 [04](04-english.md)。
7. **推薦信和研究經驗是 PhD 申請中最重要的兩項。** 從現在開始，就要經營你和 2–3 位老師之間實質的研究互動。
8. **2025–2026 年美國政策變動非常大**：F-1 固定停留期限規則剛被法院暫停、CPT 收緊、H-1B 改成依薪資加權抽籤、研究經費刪減讓 PhD 名額少了約 15%。**每到一個決策點，都要重新查最新狀態**，詳見 [07](07-reality-check.md)。
9. **地理位置會影響就業。** Bay Area、Austin、Seattle/Portland、San Diego、Phoenix 是 digital IC 重鎮；Midwest 和 Northeast 的學校很強，但畢業後多半要搬家找工作，詳見 [06](06-geography.md)。
10. **兵役、資金、心理健康、和指導教授的關係**，出發前就要想清楚。其中役男出境就學有年齡上限（碩士 27 歲、博士 30 歲），會直接影響 PhD 規劃。

## 3. 接下來 30 天就可以做的 10 件事

- [ ] 跟指導教授談一次：你的留學目標、預計時程、希望在哪個研討會投稿（先確定老師支持）
- [ ] 精讀 **LightNobel（ISCA 2025）**，另外找 5–10 篇相關論文（protein structure prediction acceleration、long-sequence attention accelerator），整理成比較表
- [ ] 在 GPU 上跑 OpenFold／Boltz／ESMFold 其中一個，量測不同序列長度 L 下的記憶體與時間分佈（這會是論文 motivation 的第一張圖）
- [ ] 考一次 TOEFL 新制的官方模擬測驗，確認起點
- [ ] 開一份選校追蹤表（範本在 [10](10-templates.md#4-選校追蹤表)），先列 30 位教授
- [ ] 上 CSRankings 勾選 Computer architecture + Design automation，看美國前 30 所學校有哪些教授
- [ ] 確認學校或實驗室能不能用 TSRI 的 EDA 工具與製程資源（synthesis/APR），或評估開源 flow（OpenROAD + ASAP7/SKY130）
- [ ] 若你是役男：查清楚「役男出境就學」的規定與年齡上限，並想好兵役怎麼安排
- [ ] 查教育部「世界百大合作獎學金」與「留學獎學金」的最新簡章，把報名期間寫進行事曆
- [ ] 建一個 GitHub 個人頁與簡單的個人網站（研究摘要、CV、論文）

## 4. 這份手冊的使用方式

- **時效性標記**：寫著「（2026/09 狀態）」的內容，是依撰寫當下的公開資訊整理，**一定會變**。做決定前請到 [09](09-resources.md) 列的官方來源再確認一次。
- **教授名單**：[05](05-schools-and-labs.md) 中標 ✔ 的教授，已在 2026/09 確認任職學校；其他人請自行確認。教授會跳槽、休假、開公司，也可能暫停收學生。
- **建議定期回顧**：每季回來看一次時程表，勾掉做完的項目、補上新資訊。這份手冊放在 git 裡，你可以直接修改，把它變成自己的申請日誌。
