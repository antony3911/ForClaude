# 雙帳號手動換手計畫（待回家討論，尚未實作）

記錄日期：2026-09-30

## 背景

- 常撞到**週上限**，考慮升級 Max 5x（約 NT$3,200）或改買兩個 Pro。
- Max 5x 官方只保證「每 5 小時用量是 Pro 的 5 倍」，週上限數字沒公布。
- 最接近官方的數字是 2025/7 公布的每週估計（Sonnet 在 Claude Code 的時數）：

  | 方案 | 月費 | 每週估計 | 約是 Pro 的幾倍 |
  |---|---|---|---|
  | Pro | US$20 | 40–80 小時 | 1x |
  | Max 5x | US$100 | 140–280 小時 | 約 3.5x |
  | Max 20x | US$200 | 240–480 小時 | 約 6x |

- 結論：如果瓶頸是週上限，而且願意手動切換，兩個 Pro（US$40）比 Max 5x 划算。
  Max 的優點是 Fable 含在額度內、尖峰優先、不用切換帳號。

## 設計：手動切換帳號，用進度檔換手

1. 在專案的 `CLAUDE.md` 加規則，讓 Claude 隨時更新 `PROGRESS.md`（草稿在下面）。
2. 帳號 A 撞到上限時：
   - 確認 `PROGRESS.md` 是最新的，並 commit（雲端 session 要 push 到 GitHub 分支）
   - `/logout`，再 `/login` 登入帳號 B
   - 開**新 session**，跟 Claude 說「讀 PROGRESS.md 接著做」
3. 不要換帳號後用 `--resume` 接很長的對話：快取是各帳號分開的，換帳號後整段對話要重讀，會吃掉一大塊額度。
4. 兩個帳號都要連 GitHub，雲端 session 的進度才能互相接手。

### CLAUDE.md 規則草稿

```markdown
## 進度紀錄
- 每完成一個步驟，就更新專案根目錄的 PROGRESS.md。
- 開新 session 時，先讀 PROGRESS.md 再開始工作。
- PROGRESS.md 只寫接手需要的資訊，保持精簡。
```

### PROGRESS.md 格式草稿

```markdown
# 進度
## 目標
## 已完成
## 下一步（第一項就是接手後要做的事）
## 重要決定與相關檔案
## 卡住的地方 / 待確認
```

## 不做的部分

- **自動偵測額度用完就換帳號的工具**：Consumer Terms 禁止用 bot、script 等自動化方式存取服務（API key 或官方明確允許的方式除外），而這種工具的目的是繞過用量限制，可能導致兩個帳號都被停權。

## 同時可以先做的省額度調整

- effort 從 xhigh 降到 high
- 一個階段做完就開新 session，或早點 `/compact`
- 查資料、寫文件改用 Sonnet

## 回家要決定 / 要做的事

- [ ] 用 `/usage` 看一週的用量，再決定買兩個 Pro 還是 Max 5x（在 claude.ai 網頁訂閱，不要在 App Store 買）
- [ ] 要不要套用上面的 CLAUDE.md 規則，套在哪些專案
- [ ] 開 Remote Control 自動連線：`/config` → Enable Remote Control for all sessions

# 遊戲 mod 工具安裝清單（2026-09-30 查證）

安裝要在家裡的電腦上做。有些安裝檔會跳 UAC，要人在電腦前按。
全部只從下面列的官方來源下載（me3 官方 FAQ 有提到防毒軟體可能誤報）。

## 共用

- **Blender 要裝兩個版本**（兩個外掛的版本需求衝突）：
  - **Blender 5.1 以上** → 法環用。Soulstruct for Blender 要求 5.1 以上
  - **Blender 4.3.2 ~ 5.0** → 魔物獵人用。RE Mesh Editor / RE Asset Library 要 4.3.2 以上，RE Mesh Editor 說 5.1 有 bug，匯入匯出會非常慢
  - 做法：一個用安裝版，另一個用 zip 免安裝版，放在不同資料夾
  - 下載：https://www.blender.org/download/
- Blender MCP（選用，讓 Claude 直接操作 Blender）：https://github.com/ahujasid/blender-mcp
- Paint.NET（選用，修貼圖）

## 艾爾登法環

| 工具 | 用途 | 來源 |
|---|---|---|
| me3 | 載入 mod（取代 Mod Engine 2） | https://github.com/garyttierney/me3/releases → `me3_installer.exe` |
| UXM Selective Unpack | 解包遊戲檔案。**只用解包，不要按 Patch** | https://github.com/Nordgaren/UXM-Selective-Unpack |
| WitchyBND | 拆開、打包遊戲封裝檔，也能把特效檔轉成文字檔 | https://github.com/ividyon/WitchyBND |
| Smithbox | 改參數（數值、戰技設定） | https://github.com/vawser/Smithbox |
| DSAnimStudio | 動作時間軸編輯與預覽（做戰技用） | https://github.com/Meowmaritus/DSAnimStudio |
| Soulstruct for Blender | Blender 讀寫法環模型，裝在 Blender 5.1 以上 | https://github.com/Grimrukh/soulstruct-blender |

me3 設定重點：mod 設定檔要寫 `savefile`（mod 專用存檔），不要開 `start_online`（預設就會擋掉官方連線）。

**Wilds 的貼圖一定要打包成 patch pak（放 `pak_mods` 資料夾），不能用散檔**，詳見 `mods/research/mhws_modding_notes.md`。

## 米凱拉風格角色（魔物獵人 Rise / Wilds）— 已決定的方向

- **不直接搬法環的模型**，以米凱拉為元素重新設計（官方設定圖、遊戲截圖當參考；別人的同人圖只參考風格）
- **身體、長袍、頭髮分開生成**，再組合、各自設定擺動（第一種做法）
- **改「人物本體」，不是做成防具**（連衣服一起設計進身體）：
  - 替換獵人不穿防具時顯示的「內衣身體」模型 → 米凱拉的身體 + 長袍
  - 替換一個捏臉的髮型 → 米凱拉的頭髮 + 擺動物理
  - 臉：沿用捏臉系統自己捏（保留表情），或另外替換臉部模型（較難）→ 待決定
- **設計要求（使用者指定）**：
  - 長袍和軀幹**分開做，再合起來**（不要一整塊）
  - **原本遊戲的內衣要完全拿掉**，長袍底下不能看到 MH 的內衣
  - 回家解包後先確認：內衣和身體在遊戲裡是同一個模型還是分開的，再決定是整個換掉還是把內衣清空
  - **身體不刪減**：長袍擺動時會看到內側，身體要完整保留
  - 防穿模：用 RE Chain Editor 的碰撞形狀（.clsp）讓長袍碰到腿、身體會被擋住；長袍和身體之間留一點空隙
  - 長袍內側要有厚度或雙面材質，否則翻起來時從內側看會是透明的
  - **服裝：一件長袍蓋全身**（不加褲子、靴子、長裙，符合原作插圖）
    - 上半身：貼合身形，不能有奇怪的起伏 → 用 Blender 從身體表面往外長出一層（shrinkwrap），保證貼合；跟著身體動，不需要物理
    - 下半身：寬鬆垂到腳踝 → 擺動物理 + 腿部碰撞；垂墜形狀可以用 Blender 布料模擬當參考
    - 布料不透明
  - **體型**：男性骨架，但走纖細、難分性別的方向
    - 胸部平坦、小腹平坦、髖部窄（男性骨盆）
    - **不要肌肉男**：小骨架、線條柔和、肌肉不明顯
    - 做法：從 MH 原本偏男性的體型模型下去改（骨架權重現成、動作比較不會變形），不用 AI 生成身體
    - **身高維持一般獵人大小，不縮小**（神人設定上體型本來就大）
    - 帶一點少年感：主要靠臉（柔和的五官）、較窄的肩膀、細一點的脖子和手腕；四肢長度維持正常，武器動作才不會出問題
  - **參考圖 1（官方，頭部特寫俯角）觀察結果**：
    - **頭冠 = 大家說的「光環」**：遊戲畫面裡它會發光，所以被稱為光環（使用者說明）。做法：發光材質（emissive），亮度和光色看遊戲截圖決定
    - **頭冠外型**：半圈，只在前額到兩側。顏色淡金偏象牙白，比頭髮稍淡。額頭中央往下凸成 V 字尖端，尖端垂一顆小水滴狀墜飾。表面有浮雕紋路，靠近尾端變成往後上方延伸的細枝纏繞造型（像樹枝）。材質有光澤，像雕刻的象牙或白木
    - **頭髮**：淡金色、非常長且蓬鬆的波浪髮，中分。中分線兩側各有一條編髮沿著頭頂往後走（跟使用者印象的「左右兩縷往後編」一致）；編髮在後面怎麼收尾要看背面圖
    - **臉**：閉眼、五官柔和、皮膚白皙帶紅暈、淡金色細眉、睫毛長
    - **衣服**：米白色、有布紋的布料；圓領，領口有一圈寬的金色滾邊
    - 做法：頭冠是硬的飾品，綁在頭骨上、不需要物理，適合用 AI 單獨生成；頭髮蓬鬆度很難在遊戲裡完全重現，只能盡量接近
  - **參考圖 2（遊戲畫面，拉塔恩戰第二階段，解析度很低）觀察結果**：
    - 頭部附近有一塊比頭髮更白、更亮的區域，有明顯光暈 → 光色偏白、帶一點暖金，亮度強
    - 解析度太低，看不出頭冠形狀，也分不出是整個頭冠亮還是局部亮
    - 頭髮在這個畫面裡也很亮、接近發光，而且非常長、飄得很開（比拉塔恩的肩膀還寬）
    - **已決定**：整個頭冠都發光（使用者確認，包含尾端細枝）；頭髮帶微光，但亮度要明顯低於頭冠，讓光環最突出
  - **參考圖 3、4（官方過場動畫，背面與側面）觀察結果**：
    - **主編髮（使用者更正）**：前額中分線兩側各一條，沿頭部兩側以接近水平的大角度往後繞（左右對稱），**在後腦正中央合成一條較粗的編髮**，再往下垂
    - **其他編髮（使用者確認）**：散髮裡另外有許多條較細的小編髮，各自垂下。整體 = 一條合成的大編髮 + 許多小編髮 + 蓬鬆波浪散髮
    - 做法補充：兩條側編髮貼在頭上、跟著頭動，不需要物理；物理從合成後的粗編髮開始
    - **長度**：非常長，蓋住整個背部，至少過腰，接近拖地
    - **袖子**：米白色長袖，比較貼手臂，長到手腕
    - **臂環**：上臂靠近手肘的位置有一圈金色、雕花的臂環
    - 做法：每條編髮做成一條獨立的擺動鏈（像繩子，物理最好做）；散髮分成幾組擺動
    - **問題**：頭髮這麼長，會跟背上收起來的武器互相穿過（MH 武器收在背上）→ 待決定：頭髮縮短到哪、或隱藏收刀時的武器（Wilds 可能有官方選項，待確認）
  - **武器（使用者提案）**：神力光劍，沒有刀鞘，**收刀時直接消失** → 同時解決長髮和背上武器穿模的問題
    - 官方選項：Wilds 的「武器顯示」只有「顯示」和「過場動畫時隱藏」，**遊戲中收刀時不能隱藏**（攻略摘要）
    - 做法：用 REFramework 的 Lua 腳本在收刀時隱藏武器。Wilds 已經有現成的「收刀自動隱藏武器」mod；Rise 待查；也可以自己寫
    - 延伸（之後再做）：拔刀、收刀時加光粒子特效，重用遊戲裡現有的特效
    - 設計方向：刀柄用跟頭冠同樣的象牙白細枝雕刻風格（整體統一）；刀身是發光的白金色光
    - 限制：沿用該武器種類原本的動作，刀身長度要接近原本的武器，攻擊判定才對得上
    - **已決定武器種類：雙劍 + 重弩**
      - 雙劍：兩把光劍；可以順便把鬼人化的紅色氣場改成金色（特效改色）
      - 重弩：收起來時也消失（重弩摺在背上，跟長髮穿模最嚴重）
    - **重弩技能「米凱拉的光」（使用者提案）**：
      - 原作參考：法環 DLC 禱告「米凱拉的光」，巨大的光柱加爆炸，施放後還會持續攻擊
      - Wilds 重弩的特殊彈：龍擊炮類（Wyvernheart 連射、Wyvernpiercer 貫通、Wyvernblast 放置炸彈、Wyverncounter），另有集中攻擊 Wyvern Howl；Rise 的特殊彈不同，待查
      - 候選：Wyvernblast → 爆炸改成光柱（最像原作）；或 Wyvernpiercer → 白金色光束
      - **使用者原則：只改畫面，不改傷害、範圍、攻擊次數**（改攻擊方式等於作弊）
      - 目標：「看起來像」從天而降、持續落下的光柱，純視覺特效
      - 路線 A：直接改原本爆炸的特效檔 → 放大、拉高成光柱、延長持續時間、改成白金色。特效檔只管畫面，傷害範圍另外定義，所以不影響攻擊。改顏色已有人做到；改大小和時間要實測
      - 路線 B：REFramework 腳本在爆炸時，於同位置額外生成幾道光柱特效（借用遊戲裡現有的光柱類特效），可以做出分好幾次落下的節奏。比較自由，但要先找出遊戲裡生成特效的函式，比較難
      - 建議：先走 A，不夠華麗再加 B
      - 注意：特效太大太亮可能遮住魔物的動作；筆電跑大量粒子可能掉幀
    - 建議順序：雙劍（練流程）→ 重弩外型 → 米凱拉人物（最難）→ 重弩技能特效
  - **光環（重點，要還原）**：
    - 已查證：遊戲道具說明提到「米凱拉閃耀的光環」（戰技「米凱拉的光環」會召喚它射出去），是一圈發光的環
    - 做法：做成發光材質的環，綁在頭部骨頭上跟著頭動；戴頭盔時也已經隱藏防具，不會擋到
    - 待確認：原作裡光環的確切位置（頭頂正上方，還是頭後方）、大小、顏色
  - **髮型（重點）**：
    - 已查證：金色（接近白金色）長髮，有編髮
    - 未查證：「左右兩縷往後編」的具體編法（相關網站這邊都打不開）
    - 回家確認的參考來源：DLC 宣傳圖、遊戲裡各地的米凱拉雕像（報導說雕像的髮型和服裝跟 DLC 宣傳圖一致）、法環原作模型（匯進 Blender 只當參考，不直接搬）
    - 做法：長髮和編髮都要設定擺動物理（RE Chain Editor），替換捏臉的其中一個髮型
  - **長袍底下**：身體 + 一件簡單的內褲，身體做成平滑、不做細部解剖構造（米凱拉是孩童形象的角色，不做裸露版本）
    - 內褲做成**幾乎零厚度、緊貼身體**（或直接畫在身體貼圖上）→ 不可能穿模到長袍外，也不會在長袍上撐出形狀
    - 內褲在下半身寬鬆的部分底下，本來就不會透出輪廓
  - 風險：翻滾、Rise 的翔蟲空中動作這類大動作，長裙可能會亂飄或穿模，要實測
- **防具透明化**：
  - Wilds：攻略網站說帳篷的「外觀」選單可以逐部位關掉防具，只顯示內衣身體（原文網站這邊打不開，回家實際確認）
  - Rise：官方選項可能不夠，應該要用 mod 把防具透明化（待查）
- 注意：捏體型的滑桿不一定能套用到新模型，體型大概要在設計時定好；內衣身體是同一體型共用的，換了之後同體型的角色都會變
- Rise 和 Wilds 的骨架不同，要各做一次 → 先選一款做
- 發佈：自己重做的模型不算搬運素材，但角色仍是 FromSoftware 的 IP
