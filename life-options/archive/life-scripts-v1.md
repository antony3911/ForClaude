# 07. 人生劇本：十種可能的五年

> 用 [00](../00-frameworks.md) 的 Odyssey Plan 概念，把前面各章的選項組合成**具體的五年劇本**。這些不是建議，是**讓你看見可能性**的草稿。
> 時間以「2027 年夏天畢業、隨即服完 4 個月兵役」為例；如果晚畢業，全部往後平移。

## 詳細劇本

### 劇本 A：美國晶片工程師（原本的計畫）
```
2027 下  當兵
2028     台灣 IC 設計（存錢、累積經驗）
2029 秋  美國 MS（USC／ASU／Texas A&M 等）
2031     畢業 → OPT → 在美國的 AI 晶片團隊
2031+    H-1B 抽籤、申請綠卡
```
- **得到**：世界中心的晶片職涯、美元薪資
- **代價**：約 US$9–20 萬、H-1B 不確定性
- **想回答的問題**：「我能在世界最頂尖的地方做 AI 晶片嗎？」
- 詳見 `study-abroad-manual/`

### 劇本 B：英國兩年（最推薦你認真考慮）
```
2027 下  當兵
2028     台灣 IC 設計；2 月和 7 月抽英國 YMS
2029     抽中 → 到 Cambridge／Bristol 的晶片公司工作 2 年
2031     帶著國際經驗：回台灣升職、轉歐洲、或申請美國 MS／PhD
```
- **得到**：2 年的英國工作經驗與生活、國際履歷、不花學費
- **代價**：要抽中；雇主可能因為只有 2 年而猶豫
- **想回答的問題**：「我喜歡在國外工作和生活嗎？」**用低成本得到答案**
- **可以和其他劇本串接**：英國兩年之後，再走 A、C 或 J 都可以

### 劇本 C：歐洲有薪 PhD
```
2027 下  當兵
2028     申請 imec（KU Leuven）、TU Delft／Eindhoven、ETH 等的 PhD 職缺（全年都可以申請）
2028–32  在歐洲讀 PhD（有薪水：荷蘭每月約 €2,900–3,700 稅前）
2032     歐洲業界（ASML、NXP、Infineon、Arm）、回台灣，或到美國
```
- **得到**：4 年歐洲生活、PhD 學位、頂尖研究網絡，而且不花錢
- **代價**：4 年；要對研究有興趣
- **想回答的問題**：「我喜歡研究嗎？我喜歡歐洲嗎？」

### 劇本 D：外商跳板
```
2027 下  當兵
2028     進入 NVIDIA／AMD／Google／Qualcomm 等的台灣團隊
2029     做滿 1 年 → 爭取內部轉調到美國（L-1）
2030+    在美國工作，再決定要不要讀書、要不要長期留下
```
- **得到**：不用付學費、不用抽 H-1B 就到美國
- **代價**：**要看公司和部門**，你無法掌控
- **可以和 A 並行**：一邊在外商工作，一邊準備 MS 申請，哪個先成功就走哪個

### 劇本 E：德國低成本路線
```
2027 下  當兵
2028     台灣工作 + 學德文（A1–B1）
2029     申請 TU Dresden 等的免學費碩士，或者用機會卡直接去德國找工作
2029–31  在 Dresden 讀書或工作（ESMC、Infineon、GlobalFoundries）
2031+    EU Blue Card → 最快 21 個月（具德語 B1）可以申請永久居留
```
- **得到**：歐洲生活、低學費、清楚的永居路徑
- **代價**：德語；德國的晶片**設計**職缺比美國少（Dresden 以製造為主）
- **想回答的問題**：「我能在非英語國家建立生活嗎？」

### 劇本 F：日本沉浸
```
2027 下  當兵
2028     日本語言學校（半年到 1 年）或日本打工度假（一生可以申請兩次）
2029     日語 N2 → 申請日本台灣交流協會獎學金讀碩士（每月約 ¥14.4 萬，外加學費和機票），或者應徵 JASM
2029–31  在日本讀書或工作
```
- **得到**：深度的文化沉浸、第二外語、日本半導體業的人脈
- **代價**：日本薪資比台灣大廠低
- **想回答的問題**：「我想在日本生活嗎？」

### 劇本 G：工程師作家
```
2027 下  當兵
2028–29  台灣 IC 設計（高薪、存錢）+ 業餘寫作：部落格、投文學獎、投稿科技媒體
2029     有作品集 → 申請 UCSC 科學傳播（1 年）或 MIT 科學寫作；或者直接轉做半導體產業分析師
2030+    科技寫作、產業分析、科學傳播的職涯；或者保持工程師身分，寫作作為副業
```
- **得到**：寫作能力、「懂晶片的寫作者」這個稀有定位
- **代價**：寫作的收入通常比 IC 設計低
- **想回答的問題**：「寫作在我人生裡應該佔多大的比例？」**先業餘寫一年，就會有答案**

### 劇本 H：HFT 的 FPGA 工程師
```
2027–28  加強演算法、低延遲設計、C++、系統知識
2028     應徵 Optiver（阿姆斯特丹有 Graduate FPGA Engineer 職缺）、IMC、Jump 等
2029+    在阿姆斯特丹、倫敦、雪梨或新加坡當 FPGA 工程師
```
- **得到**：極高的薪資、國際城市的生活
- **代價**：錄取門檻很高、工作壓力大；職涯會轉向金融科技
- **想回答的問題**：「我的 FPGA 能力能做到世界頂尖嗎？」

### 劇本 I：台灣博士 + 千里馬
```
2027     碩士畢業 → 當兵 → 直攻台灣博士
2029     博士滿一年後，申請國科會千里馬計畫
2030     到國外頂尖實驗室研究約一年
2032     畢業 → 業界研發（博士年薪可能 300 萬以上）、國外博士後，或走教職
```
- **得到**：博士學位、留在熟悉的研究圈、一年的國外研究經驗
- **代價**：時間長；教職很難
- **想回答的問題**：「我想當研究者嗎？」

### 劇本 J：歐洲商學院
```
2027 下  當兵
2028     台灣工作 1 年（MiM 多數要求全職經驗不超過 2 年）
2029     HEC／ESSEC／LBS 的 MiM，或 TU Delft／ETH 的科技管理碩士
2031     科技業的產品、策略、顧問職位，或半導體業的管理職
```
- **得到**：商學院人脈、歐洲生活、從工程轉向管理
- **代價**：MiM 學費高（ESSEC 約 €3.8 萬）；會離開技術核心
- **想回答的問題**：「我比較想做技術，還是想做決策？」

## 劇本可以串接

很多劇本不是互斥的，可以**串成一個更長的人生**：

```
英國 YMS 兩年（B）
   ↓ 發現喜歡歐洲、也喜歡研究
歐洲有薪 PhD（C）
   ↓
歐洲業界 or 美國
```

```
台灣 IC 設計 + 業餘寫作（G 的前半）
   ↓ 同時抽英國 YMS（B）
在英國當工程師，同時用英文寫作
   ↓
決定：繼續當工程師，還是轉向科技寫作或分析
```

```
外商台灣（D）
   ↓ 轉調不成
美國 MS（A）
```

## 怎麼選：從你最在乎的事開始

| 如果你最在乎…… | 優先看的劇本 |
|---|---|
| **閱歷**，而且不想花太多錢 | B（英國兩年）、C（歐洲 PhD）、F（日本） |
| **世界頂尖的晶片職涯** | A（美國 MS）、D（外商跳板）、C（歐洲 PhD） |
| **寫作** | G（工程師作家），再搭配 B |
| **收入** | H（HFT）、台灣大廠、D |
| **學術／研究** | C（歐洲 PhD）、I（台灣博士 + 千里馬） |
| **長期移民、有清楚的身分路徑** | E（德國）、加拿大 MS（見 [02](study-abroad-by-country-v1.md)）、C |
| **保留最多選擇** | 先在台灣工作 + 每年抽英國 YMS + 業餘寫作。**這三件事可以同時做** |

## 最後一個建議：同時做三件「低成本、高資訊量」的事

在你還沒決定之前，下面三件事幾乎不花錢，但能給你很多資訊：

1. **每年 2 月、7 月抽英國 YMS**：抽中了再決定要不要去
2. **開始業餘寫作**：一年後你會知道寫作對你有多重要
3. **跟三個走不同路的人聊天**：例如一位在歐洲讀 PhD 的台灣人、一位在英國或日本工作的工程師、一位從工程轉做分析或寫作的人（LinkedIn、PTT、Dcard 都找得到）

> Designing Your Life 的建議是：**用「原型」代替「空想」**。和真正走過那條路的人聊 30 分鐘，勝過自己想三個月。
