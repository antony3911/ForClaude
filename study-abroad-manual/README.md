# 美國研究所留學手冊：Digital IC × AI 加速器方向（MS 版）

> 最後更新：2026-09-26（v2：改為以 MS 為主，PhD 作為備案）
> 對象：台灣 EE/CS 碩士生，目前在 HW/SW co-design 實驗室做 FPGA 加速器，研究題目是**長序列蛋白質結構預測的加速**。計畫到美國**再讀一個碩士**，之後留美做 digital IC design，往 AI accelerator 發展。

## 0. 前提假設

| 項目 | 假設 |
|---|---|
| 身分 | 台灣的碩士生（或即將畢業），EE/CS 背景 |
| 目前能力 | FPGA 加速器設計、HLS/RTL、HW/SW co-design；**還沒有**完整走過 ASIC flow |
| 研究 | 長序列蛋白質結構預測的硬體加速 |
| 主要目標 | **美國 MS（第二個碩士）** → OPT → 留美做 RTL/DV/PD，逐步往 AI 加速器架構發展 |

| 時程 | 以**送件截止日**為基準往回推，分兩種情境（見下方） |

| | 情境 A | 情境 B |

| 送件 | 2027/12 – 2028/01 | 2028/12 – 2029/01 |

## 1. 一頁結論（TL;DR）

1. **「第二個碩士」在很多名校是受限的，選校要先做這一步。** 查證結果（2026/09）：
   - **原則上不收**同領域第二碩士的學校：Berkeley EECS（MS）、UCSD、UIUC、Michigan ECE、NC State；UCLA 要求提出「充分理由」
   - **可以申請，但要在 SOP 說明理由**的學校：Stanford EE、CMU ECE
   - **明確允許**的學校：USC（但不能重修、學分不能抵）
   - Georgia Tech 只「強烈不建議」已有**美國** ECE 碩士的人申請，台灣碩士不在此限
   - 詳見 [05](05-schools-and-labs.md#51-第一步確認第二碩士資格)
2. **⚠️ 未服役男生的兵役問題。** 出國讀書要辦役男出境核准，碩士班的年齡上限是 27 歲。**畢業後一旦不在學，役政單位會催告 3 個月內返國，否則依法移送**，護照也不能正常延期。也就是說，**「讀完 MS 用 OPT 留美工作」這條路，未服役的男生幾乎走不通**，建議出國前完成兵役或研替。詳見 [07](07-reality-check.md#74-役男兵役)。
3. **MS 是一張「進入美國招募管道的門票」。** 你付出約 US$9–20 萬，換到美國學歷、實習機會、最多 3 年的 OPT 工作許可，以及 3 次 H-1B 抽籤機會。
4. **H-1B 是 MS 路線最大的風險。** 2026 年起改為依薪資加權抽籤，新鮮人職位如果被歸在最低的 Level I，中籤率估計只有約 15%。一定要準備 Plan B（見 [07](07-reality-check.md#72-工作簽證與移民路徑的現實)）。
5. **求職從入學第一天就開始。** 暑期實習的招募在 8–11 月，你一到美國就要能面試，**RTL 面試能力要在出國前練好**。
6. **CPT 在 2026/08 變嚴了。** 新指引要求實習必須是課程裡所有學生都要修的必修項目。MS 通常只有一次暑期實習機會，選校時要把「實習是否列為必修」納入考量。例如 CMU ECE 的 Applied 課程就把實習列為必修。
7. **研究經驗是你的差異化武器**，雖然 MS 申請更看重 GPA 和學校背景。研究經驗能讓你爭取 MS 的 RA 或 thesis、在面試中有深度的話題，也保留申請 PhD 的可能。**研究照樣做完、論文照樣投。**
8. **把 FPGA 經驗補成 ASIC 經驗**：跑一次 synthesis 和 APR，拿到 PPA 數字。這對 MS 求職比對 PhD 申請更重要。
9. **英文**：TOEFL 目標 overall 5.0–5.5（約等於舊制 100 分以上）。多數 MS 不需要 GRE（USC、Georgia Tech、UW 都不需要）。
10. **地點會影響實習和求職**：Bay Area、Austin、Seattle/Portland、San Diego、Phoenix 附近的學校，在找實習時有地利之便。

## 3. 接下來 30 天就可以做的 10 件事

- [ ] **如果你是未服役的男生：先把兵役規劃想清楚**（出國前服役或研替？），這會決定你是情境 A 還是 B
- [ ] 列出 15–20 個 MS 候選課程，**逐一確認「已有台灣碩士者能不能申請」**；官網沒寫的，就用 [10](10-templates.md#1-詢問系所第二碩士資格的信) 的範本寫信問
- [ ] 跟指導教授談一次：你的留學規劃、研究的投稿目標，以及推薦信
- [ ] 考一次 TOEFL 新制的官方模擬測驗，確認起點
- [ ] 確認學校或實驗室能不能用 TSRI 的 EDA 工具與製程資源，規劃 ASIC implementation
- [ ] 開始練 RTL 面試基本題：FIFO、arbiter、FSM、CDC（可以先用 HDLBits 練習）
- [ ] 開一份選校追蹤表（範本在 [10](10-templates.md#4-選校追蹤表)）
- [ ] 算清楚預算：各校的 Cost of Attendance、家裡能支援多少、要不要貸款
- [ ] 查教育部留學獎學金的最新簡章（碩士也能申請）
- [ ] 建一個 LinkedIn 帳號和 GitHub 個人頁（美國求職會用到）
