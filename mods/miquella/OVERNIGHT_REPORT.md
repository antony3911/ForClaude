## 這次最重要的發現

1. **整條「做模型 → 遊戲檔案」的流程在沒有遊戲的情況下跑通了**：程式建模 → 減面 → 烘焙法線貼圖 → RE 引擎格式貼圖 → `.tex` → 用 Wilds 預設建 `.mdf2` → 匯出 `.mesh`，全部可以重新匯入驗證。
2. **Wilds 的貼圖一定要打包成 patch pak**（放 `pak_mods`），不能用散檔。RE Mesh Editor 有「Create Pak Patch」可以做。
3. **Blender 版本**：魔物獵人的工具要用 **4.3.2–5.0**（5.1 有匯入匯出變很慢的問題）；艾爾登法環的 Soulstruct 要 5.1 以上 → 兩個版本都要裝。
4. **遊戲檔案路徑**（檔名清單 ＋ MDF-XL 的資料庫交叉確認）：雙劍 `it02`（`_0` 左手、`_1` 右手）、太刀 `it03`（`_1` 是刀鞘）、片手劍 `it01`（`_1` 是盾）、重弩 `it12`、輕弩 `it13`；**男性內衣是 `ch02_002` 系列的四個部件**（我之前猜的 `ch02_000_0006` 是錯的，那是投射器）；捏臉髮型在 `ch01/000/0/`；男性骨架是 `ch02_000_9000.fbxskel`。
5. **頭髮材質沒有發光參數**：頭髮的微光要換方法（提亮、VFX 混合，或讓編髮用可發光的材質）。見研究筆記第 14 節。
6. **可以不覆蓋任何原版檔案**：MDF-XL 用腳本在遊戲中生成新物件、掛到獵人骨架上（`set_SameJointsConstraint`），武器也能在執行中換模型。米凱拉的身體、長袍、頭髮、光劍都可以走這條路 → 不用犧牲任何一件內衣、髮型或武器外觀，也能用選單開關。見研究筆記第 15 節。
7. **弩可能比較麻煩**：MDF-XL 的換裝資料庫裡沒有重弩和輕弩，弩可能是組裝式的模型。

## 回家要做的事（照順序）

1. 裝 REFramework、Fluffy Mod Manager、Blender 4.3.2–5.0、RE Mesh Editor、RE Asset Library（清單在 `notes/two-account-handoff-plan.md`）
2. **跑偵察腳本**（`mhws/MiquellaLight_Scout/`，只讀取不改東西）：在 REFramework 選單按「Scan hunter」再按「Save report」，把 `reframework/data/MiquellaLight/scout.json` 給我 → 武器、內衣、髮型的路徑和骨頭名稱一次確認
   - 分別拿雙劍、太刀、片手劍、重弩、輕弩各掃一次（穿內衣、不戴頭盔更好）
3. **選一把要被替換的雙劍**，照素材包 README 的 7 個步驟做 → 這會是第一個真的能在遊戲裡看到的東西
4. 測收刀隱藏腳本（REFramework 的 Script Generated UI 裡會有選單）
5. 用 MDF-XL 在遊戲裡調發光顏色和強度

## 需要你決定的事

- **覆蓋原版檔案，還是用腳本掛上去**：我建議腳本掛載（第 6 點），不會犧牲任何原版外觀；如果腳本那條路在遊戲裡行不通，再退回覆蓋檔案
- **（如果要覆蓋檔案）替換哪一把原版武器**：選你不會用到的外觀，因為替換後原本那把就看不到了
- **頭髮微光的做法**：四個選項都要實測，我個人建議先試「編髮發光、散髮不發光」，最接近參考圖的光感
- **捏臉髮型要替換哪一款**：同上，選一款你不會用的
